# MVP-04 extraction and inspector operator guide

Apply migration `0008` through `0010` after backing up the retained PostgreSQL database and immutable object storage. The extraction additions are additive. A captured source version must already exist through MVP-03 local or scoped SharePoint sync. No extraction reads or writes the original source tree; it reads the verified immutable snapshot.

**Deployment dependency decision:** PyMuPDF is offered under AGPL or a commercial Artifex license ([official license terms](https://pymupdf.readthedocs.io/en/latest/about.html#license-and-copyright)). Before a non-evaluation deployment, the owner must document how this application satisfies AGPL requirements, obtain a commercial license, or approve a replacement parser. This PR's offline synthetic validation does not establish license compliance. Preserve the decision with the deployment record.

Open the collection screen and follow **Inspect source version**. The inspector shows the captured path, version ID, snapshot SHA-256, and an authorized download of the exact captured bytes. Select **Extract or reuse cached result**. A successful run shows each parser unit in source order with page, section, paragraph, slide, sheet/cell, or table locator, neighboring text, warnings, parser version, and run fingerprint. Figures are stored separately and displayed with source locators and nearby captions. They are not automatically digitized or treated as model facts. A failed, empty, encrypted, scanned, unsupported, or oversized input shows a reason and recovery action. Past runs remain selectable.

**Re-extract as a new version** preserves prior unit IDs and citations. A changed extractor, schema, parser selection, or relevant extraction setting changes the cache fingerprint. Historical publication citations resolve to the original unit. Newly parsed units are unclassified and cannot enter the MVP-02 factual publication flow; MVP-05 will determine their support kind. A review of an extracted source is scoped to its active run. For versions captured before migration `0008`, the exact path at capture was not retained; the inspector falls back to the current source path and operators should treat that path as uncertain. New captures record `observed_path`.

For a scanned page, request a selective OCR inspection by page number. If `PROPOSAL_LOCAL_OCR_EXECUTABLE` points to a local Tesseract-compatible command, the task can render that single captured page and invoke OCR with a timeout. The command is disabled by default. The OCR candidate stays labeled **derived** and **needs source check**. A reviewer compares it with the source page, records uncertainty and corrections, then completes the task. The same source-check form handles a selected figure. At most five visual tasks are allowed per source version by default; text, page pixels, parser and OCR time, document size, archive inflation, and unit counts are bounded in `config/default_config.yaml`. The parser runs in a timed local process with private temporary files. There is no paid visual provider and no automatic promotion of derived text into factual units.

For private seed-family calibration in MVP-08/09, run:

```powershell
& '.venv\Scripts\python.exe' scripts/manage.py audit_extraction --collection '<collection-uuid>' --per-family 5
```

The command prints version IDs, inspector paths, states, parser reasons, unit/figure/warning counts, and a deterministic sample from each family. It prioritizes failed and figure-bearing versions. Keep the manifest and all real labels, excerpts, and screenshots in private evaluation storage. For each sampled version, compare original bytes with inspected units and record whether headings, signs, exponents, units, table headers, captions, notes, and section boundaries survived. Record numerator/denominator per family and exact missed unit IDs; do not infer scientific accuracy from synthetic fixtures alone. The harness intentionally prints no source text.

If extraction fails, retain the snapshot and prior run. Use the displayed recovery action: alternate parser, selective page OCR, authorized local conversion to a **new captured source version**, or deferral. ZIP/email and legacy Office formats remain explicit conversion cases. Never overwrite the snapshot or mutate historical units. To stop the new parser, stop initiating extraction; existing runs and citations remain available. To reverse the schema on a disposable development database, migrate back to `0007` only after confirming there is no retained MVP-04 data. For retained data, restore a verified database and object-storage backup in an isolated environment. A deployment rollback must not reactivate a publication excluded by a newer decision.
